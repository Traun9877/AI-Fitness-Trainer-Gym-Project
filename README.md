# 🏋️ AI Fitness Trainer Gym Project

An AI-powered Fitness Trainer that uses Computer Vision and Human Pose Estimation to track workouts, count repetitions, and provide real-time exercise feedback. The system leverages MediaPipe and OpenCV to analyze body movements and help users perform exercises with proper form.

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Traun9877/AI-Fitness-Trainer-Gym-Project.git
cd AI-Fitness-Trainer-Gym-Project
```

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Project

```bash
python main.py
```

The webcam will open automatically and start tracking your exercise movements.

## 🧠 How It Works

1. Webcam captures live video.
2. MediaPipe detects body landmarks.
3. Joint angles are calculated.
4. Exercise movement is analyzed.
5. Repetitions are counted automatically.
6. Real-time feedback is displayed.
